Project Overview

QuestLogs is an adaptive web interface built for gaming and streaming enthusiasts. Designed with a dark-mode theme and glowing RGB highlights, the single-page application features interactive storyboards, functional streaming gear inspect panels, and playable newsgame simulations without cart dependencies.

Concept & Mission

QuestLogs takes inspiration from classic anti-corporate newsgames like The McDonald's Video Game. Rather than operating strictly as a storefront, QuestLogs utilizes interactive media to present social commentary on fast-food inflation and modern consumer economics.
