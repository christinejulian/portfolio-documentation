# portfolio-documentation
I created this QuestLogs portfolio documentation website to showcase the design, development, and ideas behind my interactive gaming platform. The website documents the different sections of QuestLogs, including the video game center, gaming hardware store, UI storyboard, and interactive fast-food inflation simulator. I wanted to show how I combined e-commerce features with interactive games and social commentary to create a unique gaming-focused experience. I built the project using HTML, with CSS and JavaScript elements incorporated into the code, and used the site to document my design process, inspiration, and interactive features. This project helped me develop my skills in web design, user interface design, interactive media, and game development.
